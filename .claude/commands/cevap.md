description: QUESTIONS.md sorularını gösterir veya cevapları uygular
---
docs/QUESTIONS.md'yi oku. Yoksa "bekleyen soru yok"
de ve dur.

"Cevap:" alanları boşsa:
- Cevaplanmamış soruları numara + başlık + soru +
  seçenekler + senin varsayımın şeklinde KISA
  listele. Uzun açıklama yazma. Sonra bekle.

"Cevap:" alanları doluysa:
1. Cevap senin varsayımınla aynıysa soruyu
   "ÇÖZÜLDÜ" işaretle, kodu değiştirme.
2. Farklıysa kodda // SORU: S<no> geçen tüm yerleri
   bul, cevaba göre düzelt.
3. npm run build ile derlemenin geçtiğini doğrula.
4. Gerekiyorsa docs/PLAN.md'ye yeni madde ekle.
5. Commit'leyip push'la, kısa özet ver.
6. Sonra otonom çalışmaya geri dön.
